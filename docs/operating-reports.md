# 经营及分红月报

## 页面与入口

独立页面为 `/expense/monthly/operating`（支持尾斜杠）。报表顶部提供带箭头的「经营月报 / 支出月报」下拉切换，支出月报为现有 `/expense/monthly` 页面。两页共享切换器并保留门店、月份参数；选中项标记，支持键盘方向键、Esc 和点击空白收起。报账后台主入口位置仍待决定。

页面使用原生 HTML/CSS/JS，沿用报账月报的配色、门店/月份切换及深浅色偏好。没有 React、CDN 或内联脚本依赖。静态文件位于 `src/admin/public/operating/`，由现有构建流程复制。页面、资源和接口均验证 `report:view` 与 `report:monthly:view`，响应禁止缓存。

## 成本数据

直接复用 `readMonthlyRecords`、`monthlyCategoryTotals` 和 `monthlyTotals`，与报账月报相同门店、月份、时区、账号范围、币种同步读取，不保存成本快照。

固定显示食材、工资、房租、水电、花卉、其他六类，按原始 `expenseCategory` 汇总。工资/花卉不从备注或 OCR 识别；房租包含原始房租类别的各项记录。店长报账、预报账等未单列类别并入其他；店长渠道里的食材类别仍计入食材，与原月报分类概览一致。六类金额合计等于总支出。

成本构成比例以本币种已知总支出为分母。总成本率与盈利率以已录入总收入为分母。不同币种不相加；未知币种单独显示。金额缺失时显示已知支出/待确认，当前币种有金额缺失或有未知币种时不计算盈利与总成本率。负数成本仍参与金额合计，但存在负数类别合计时不画占比条。零收入时比率显示横线，盈利可正常为负数。空月六类为零，收入和分红仍待录入。

## 手工录入

用户已选择按门店和月份手动录入总收入、营业收入、总分红及各项分红，后续提供各店表格。当前没有预填截图金额、默认分红人或固定比例。

完整门店可见范围且拥有 `report:edit` 的账号可编辑。仅本人或部分渠道权限的账号只看到相应成本，不读取/输出整店收入、分红或备注，不能编辑。现有权限未新增、自动授予或扩展。

- 总收入、营业收入、总分红可留空（待录入），0 为明确无收入/无分红。
- 非负金额，最多两位小数，整数分安全精度。最多 20 项分红，名称必填、不重复，最多 100 字。
- 分红明细合计不得超过总分红；可先保存总分红，剩余部分显示待分配。不会按盈利自动生成分红。
- 盈利自动按总收入减总支出计算；部分查看范围下不显示整店盈利。
- 备注最多 2000 字；所有用户文本转义后渲染，CSV 对公式起始符做转义。
- 保存以修订版本做乐观锁，冲突返回 409，保留当前表单并提示重新载入，防止静默覆盖。

幂等迁移新增 `monthly_operating_reports` 表，以 `(store_id, month, currency)` 唯一保存收入、分红总额、明细、备注、修订版本、操作者与更新时间。不修改报账记录或历史月账归属，不新增机器人任务。

## API

门店/月选择沿用 `GET /expense/api/monthly-reports/options`。

- `GET /expense/api/monthly-reports/operating?month=YYYY-MM&store=fuzzy&currency=CNY`：实时成本、手工收入/分红、派生盈利、可编辑能力；币种默认为 CNY。
- `PUT` 同地址：`{ incomeCents, operatingIncomeCents, dividendCents, allocations: [{ name, amountCents }], note, revision }`。首次 revision 为 0，其后使用读取到的版本。只接受 JSON，验证来源和当前账号权限及完整门店范围。
- `GET /expense/api/monthly-reports/operating/export` 使用相同参数：CSV 导出同一可见范围下的金额与待确认状态。

月份范围沿用月报：管理员最早 `1900-01`，其他人员从 `2026-09`，默认上个月。非法参数、金额、版本或分红明细返回 400；越权 403/404；并发冲突 409。

## 验证

`npm test` 包含 `src/admin/operating-report.test.ts`：六类与月报一致、原始类别语义、保存持久化、原报账不改写、成本实时更新、币种/门店/月隔离、部分权限不泄露整店数据、撤权、并发冲突、零与空值、缺失/负数成本、CSV 公式转义及历史月份权限。

浏览器验收使用临时 SQLite 和模拟网关，验证真实页面与接口、录入/保存/刷新、校验反馈、门店和月份切换、深浅色与窄屏。浏览器模拟不是手机实机证明。生产部署与菜单入口另行安排。

总收入（`incomeCents`）与营业收入（`operatingIncomeCents`）独立保存。概览主值为总收入，下方显示营业收入金额；未提供营业收入时显示待录入，不用总收入代填。新增 `operating_income_cents` 列以 NULL 初始化，保留原收入字段数值及修订版本。本月盈利标题与金额沿用系统绿色，深浅色各使用对应色值。
