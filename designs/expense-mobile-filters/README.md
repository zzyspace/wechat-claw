# /expense 手机端筛选布局对比

入口：`index.html`。提供 A 行内折叠、B 紧凑工具栏、C 底部面板、D 按项展开四个高保真交互版本，分别可通过 `a.html`、`b.html`、`c.html`、`d.html` 独立打开。

## 设计依据与边界

- 用户确认：沿用现有风格，对比四种布局。门店与创建日期常驻，关键词、报账人、类别、备注默认折叠。
- 视觉来源：`../../src/admin/public/admin.html`，2026-09-27 本地源文件；沿用 `#007aff`、`#f2f2f7`、`#1c1c1e`、深色变量、CJK 系统字体与 20px 面板圆角。没有导入独立设计系统。
- 控件和文案按源页面重建，背景保留现有灰色。原有报账查看后台标题、说明、补录入口和记录样式作为上下文。
- 使用虚构数据，不访问任何业务 API，不改变登录、报账、附件或生产环境。预览中日期固定为 2026-09-27。
- 日期范围、查询、重置、条件移除、深浅主题、无结果和输入校验可操作；报账详情仅展示示例。复合语法保留 `!`、`&`、`||`；预览类别仅为演示子集，后续实际实施应复用服务端解析器。
- C 面板内部是草稿，关闭不应用；A/B/D 折叠保留表单输入。已生效的隐藏条件以可移除标签呈现。
- 对比画布使用 baoyu-design 的 `design-canvas.jsx`；交互状态由 React 18.3.1 管理。React 与 ReactDOM 库在 `vendor/` 内，运行不依赖 CDN。JSX 已编译为浏览器 JS。

## 本地预览

在仓库运行 `python3 -m http.server 4312 --bind 127.0.0.1 --directory designs`，打开 `http://127.0.0.1:4312/expense-mobile-filters/index.html`。

用户已选择 A 行内折叠，已应用到本地 `src/admin/public/admin.html`。其他方案保留作对比。尚未部署。

实施验证见 `implementation/qa.json`：手机 320–620px 深浅色、桌面 768/900/1440px 布局前后对比、筛选参数、条件标签、日期选择、错误处理和店长权限均通过浏览器模拟验证。真实手机 Safari/微信尚未验证。
